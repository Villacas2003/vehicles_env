# Entornos virtuales
Proyecto Sprint 7 
Proyecto: vehicles_env

Este proyecto corresponde a un entorno de desarrollo en Python orientado a la gestión, simulación o análisis de datos relacionados con vehículos.

🌎 Descripción General

Este repositorio contiene el código fuente y dependencias necesarias para trabajar en el entorno de vehicles_env. El objetivo principal fue configurar un entorno Python reproducible y funcional para el desarrollo y la ejecución de scripts relacionados con datos vehiculares.

🔧 Tecnologías y Herramientas Utilizadas

Python 3.x

Entornos virtuales (venv)

Git

Visual Studio Code (VS Code)

Archivo requirements.txt para gestión de dependencias

🔄 Instalación y Configuración

1. Clonar el repositorio

git clone https://github.com/usuario/vehicles_env.git
cd vehicles_env

2. Crear el entorno virtual

python -m venv venv

3. Activar el entorno virtual

En Windows:

.\venv\Scripts\activate

En macOS/Linux:

source venv/bin/activate

4. Instalar dependencias

pip install -r requirements.txt

5. Abrir en VS Code

Abre la carpeta del proyecto en VS Code.

Selecciona el entorno virtual como interpreter de Python.

📅 Estado del Proyecto

Entorno correctamente configurado y listo para:

Ejecutar scripts.

Desarrollar nuevas funciones.

Integrar APIs o sistemas de análisis de datos vehiculares.
